# Cryptopals Challenges

My solutions to the Cryptopals cryptography challenges.
The challenges can be found on https://cryptopals.com/

The challenges cover topics such as:
- XOR and block ciphers
- AES
- ECB/CBC modes
- Hash functions
- MACs
- Cryptographic attacks
- Padding oracles

## Purpose

I am working through these challenges to improve 
my understanding of practical cryptography and 
to gain more programming experience implementing 
and attacking cryptographic systems.

The Cryptopals challenges provide a way to explore both sides:
understanding cryptographic concepts mathematically while 
implementing algorithms and attacks in code.
